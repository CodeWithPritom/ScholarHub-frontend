## 📖 Executive Summary

**ScholarHub AI** is an enterprise-grade academic research intelligence and systematic literature synthesis platform designed to unify the fragmented landscape of modern scientific discovery. By querying federated global academic databases (**PubMed/NCBI, PubMed Central, arXiv, OpenAlex, Europe PMC, CrossRef, DataCite, DOAJ, Zenodo, and Unpaywall**), ScholarHub provides real-time access to over **250+ Million research works** with deterministic metadata deduplication, journal quartile classifications (SJR Q1–Q4), and AI-grounded literature synthesis.

Equipped with an autonomous **Cognitive Research Auditor**, a **Universal Visualization Engine (UVE v2.0)**, a **Multimodal Vision RAG Pipeline**, and an interactive **Research DNA** system, ScholarHub empowers university faculty, researchers, graduate students, and independent scholars to conduct systematic literature reviews, extract verifiable empirical evidence with zero hallucination, generate interactive scientific charts, discover funding opportunities, and accelerate their academic careers in minutes rather than months.

## 💻 Local Development & Setup

### Prerequisites
- Node.js 18.x or 20.x
- npm or pnpm

### 1. Clone the repository
```bash
git clone https://github.com/CodeWithPritom/ScholarHub-frontend.git
cd ScholarHub-frontend
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure environment variables
Create a `.env` file in the root of the frontend directory:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_BACKEND_URL=https://api.scholarhub-ai.com
VITE_CLOUDFLARE_SITE_KEY=0x4AAAAAADMiMm356ph5tSi8
```

### 4. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Build for production
```bash
npm run build
```
